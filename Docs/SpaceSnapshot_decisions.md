## Новый текст раздела 4.10 (заменяет прежний)

### 4.10. SpaceSnapshot (снимок пространства)

| Поле | Тип | Описание |
| --- | --- | --- |
| id | строка | Идентификатор снимка |
| capturedAt | дата | Время снимка, ISO 8601, UTC |
| planes | список | Плоскости (см. ниже) |
| volumes | список | Крупные объёмы (см. ниже) |
| floorHeight | число | Высота пола, м, в системе сессии сканирования |
| quality | целое | Качество сканирования, 0-100 |

**Система координат.** Все `center` в снимке заданы в системе сессии сканирования, как их отдаёт MRUK (метры, Y вверх). Связь с системой проекта задаётся через Alignment (offset + rotationY). Для проекта, созданного по скану, Alignment единичный, и системы совпадают.

**Поворот.** Только `rotationY`, градусы. Положительный угол считается как в Unity: вокруг оси Y, по часовой стрелке при взгляде сверху. Кватернионы не используются.

**Plane** (`planes[]`): `id`, `kind`, `center` (Vec3), `rotationY`, `size` (Size2: `width`, `height`).

| kind | width | height | Примечание |
| --- | --- | --- | --- |
| wall | длина вдоль стены | вертикаль | rotationY = 0: продольная ось стены направлена вдоль +X |
| door, window | ширина проёма | высота проёма | то же правило поворота, что у стены |
| floor, ceiling | размер вдоль локальной оси X после rotationY | размер вдоль Z (глубина), НЕ вертикаль | плоскость горизонтальна на высоте center.y; непрямоугольный пол заменяется ограничивающим прямоугольником |

**Volume** (`volumes[]`): `id`, `label`, `center` (Vec3), `rotationY`, `size` (Vec3: ширина, высота, глубина).
- `center` объёма: геометрический центр. `size`: полные габариты.
- Допустимые `label`: `table`, `sofa`, `bed`, `cabinet`, `chair`, `other`. Валидатор отклоняет остальные значения.
- Маппинг меток MRUK делает A: COUCH -> sofa, STORAGE -> cabinet, TABLE -> table, BED -> bed, остальное -> other. Метки `chair` из скана не появляются (используется только для проектных предметов).
- Для сравнения (A-11) для напольных предметов проекта: center.y = pivot.y + size.y / 2.

**quality (0-100).** MRUK оценку не отдаёт, поэтому правило задаёт A (предложение, согласовать): 40 баллов за наличие пола, 20 за потолок, 40 за долю найденных стен от четырёх (минимум), затем ограничить диапазоном 0-100.
